🔍 Punts Cecs del Sistema

Basat en l'anàlisi del bundle 260911_1802_BUNDLE_auditoria.md.

⚠️
ATENCIÓ: Aquests són els problemes que causen al·lucinacions en les IAs.

🔴 Punt Cec #1: Tipografia

Problema:

Una IA va interpretar els H3 amb tipografia Serif i colors inventats.

Causa:

El CSS no declarava explícitament font-family: inherit per a tots els elements.

Solució:

h1, h2, h3, h4, h5, h6, p, span, div, a {
  font-family: inherit;
}

Estat:

✅ CORREGIT en aquesta demo

🔴 Punt Cec #2: Duplicitat

Problema:

Existeixen dos fitxers UniversalCard.jsx:

  • src/components/ui/UniversalCard.jsx
  • src/components/universal/UniversalCard.jsx

Risc:

Conflictes d'importació, manteniment duplicat, inconsistències.

Solució:

Unificar en una sola ubicació. Recomanació: src/components/universal/

Estat:

❌ PENDENT

🟡 Punt Cec #3: Tokens de Disseny

Problema:

Falta documentació per a design-tokens.json i design-tokens.css.

Risc:

Diferents IAs poden interpretar els tokens de manera diferent.

Solució:

Crear un STYLEGUIDE.md que expliqui:

  • Paleta de colors i significat
  • Escala d'espaiats
  • Jerarquia tipogràfica
  • Exemples d'ús

Estat:

⚠️ RECOMANAT

🟡 Punt Cec #4: CSS Massiu

Problema:

index.css té 4554 línies - massa gran per a un únic fitxer.

Risc:

Conflictes de especificitat, difícil manteniment, lent per processar.

Solució:

Dividir en mòduls:

  • base.css - Reset i estils base
  • components.css - Estils de components
  • utilities.css - Classes utilitàries
  • themes.css - Variables i temes

Estat:

⚠️ RECOMANAT

🟡 Punt Cec #5: Paleta de Colors

Problema:

No hi ha una paleta de colors centralitzada i documentada.

Risc:

Colors inconsistents en diferents components.

Solució:

:root {
  --color-primary-50: #f0fdfa;
  --color-primary-100: #ccfbf1;
  /* ... */
  --color-semantic-success: #10b981;
  --color-semantic-warning: #f59e0b;
  /* ... */
}

Estat:

✅ IMPLEMENTAT en aquesta demo

🟡 Punt Cec #6: Jerarquia de Títols

Problema:

No està clar com s'estilitzen H1, H2, H3, etc.

Risc:

Inconsistència visual entre diferents seccions.

Solució:

Documentar en un typography.md:

  • Mides de font per nivell
  • Colors per defecte
  • Marges i espaiats
  • Peso (bold, normal, etc.)

Estat:

⚠️ RECOMANAT
