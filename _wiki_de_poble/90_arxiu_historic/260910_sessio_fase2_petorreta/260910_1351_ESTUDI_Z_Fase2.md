# 🧠 ESTUDI CONSELL: Z (Fase 2)

Z ha analitzat de forma estructural el manifest i aporta una visió brillant, afegint vulnerabilitats crítiques no vistes per la resta del Consell i un pla arquitectònic molt clar ("Graella + Illes").

### 1. Noves Vulnerabilitats Crítiques
- **V8. Sense ErrorBoundary:** Cap component de contenció en tot el projecte. Un error de render = pantalla blanca global.
- **V10. Sessió Inmortal:** La sessió no es purga en memòria (contextos) quan es tanca sessió. Risc a dispositius compartits.
- **V9. Doble Veritat Editorial:** ~250KB de text (`pageContent.js`, `i18n.js`) viuen **compilats dins el JS**. A x10 el pes creixerà pel text i no pel codi.
- **V7. Curses d'inicialització:** El router, la sessió i la UI col·lideixen en carregar. Falta un registre de Loaders.

### 2. Pla d'Arquitectura "Graella + Illes"
Z proposa no introduir cap eina pesada, sinó usar `react-dom/server` i `@layer` nadiu:
- **Graella (`AppGridShell`):** Marc estàtic prerenderable.
- **Illes:** Components vius (Xat, Editor) que s'hidraten sota demanda.
- **Router partit:** `resolver.js` (isomorf) + `browserAdapter.js` (client).

### 3. Ordre d'Execució de Z (Molt pragmàtic)
- **Fase 2A — Xarxa:** Col·locar l'ErrorBoundary global, crear Loaders per matar les curses, purgar llavors del build, i partir l'i18n. La xarxa de seguretat abans del trapezi.
- **Fase 2B — Pedres:** Deconstrucció CSS amb `@layer legacy` per evitar regressions, cens de selectors.
- **Fase 2C — Murs:** Fragmentació de components via el patró estrangulador (index de re-exportació).
- **Fase 2D — Illes:** Prerenderat SSR + Hidratació.
