## 1. INFORME DE PUNTS CECS

L'anàlisi del bundle 260911_1802_BUNDLE_auditoria.md ha revelat 8 punts cecs principals que causen al·lucinacions en les IAs (com l'incident reportat on una IA va interpretar H3 amb tipografia Serif i colors inventats).

Prioritats:
- 🔴 2 Punts Crítics (Resoldre URGENT)
- 🟡 4 Punts Alts (Resoldre en propera iteració)
- 🟢 2 Punts Mitjans (Millora contínua)

### 🔴 PUNTS CRÍTICS (PRIORITAT MÀXIMA)

**1. 🔥 Ambigüitat Tipogràfica - H3 amb Serif**
Problema: Una IA va interpretar els elements `<h3>` amb tipografia Serif i colors inventats. Això indica que el sistema de disseny no comunica clarament les regles tipogràfiques.
Anàlisi: El manifest no especifica explícitament que TOT el text ha de ser Sans-Serif. No hi ha declaració CSS global que forci `font-family: sans-serif` per a tots els elements. Les IAs poden inferir regles incorrectes sense documentació clara.
Solució Implementada:
```css
:root {
  --font-family: 'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif;
}
/* Forçar SANS-SERIF per a TOTS els elements */
h1, h2, h3, h4, h5, h6, p, span, div, a, li, td, th, label, button, input, textarea, select {
  font-family: inherit;
}
body {
  font-family: var(--font-family);
}
```

**2. 🔥 Duplicitat de Components - UniversalCard.jsx**
Problema: Existeixen DOS fitxers idèntics amb el mateix nom:
- `src/components/ui/UniversalCard.jsx`
- `src/components/universal/UniversalCard.jsx`
Anàlisi: Ambdós tenen el mateix hash SHA256. Això causa conflictes d'importació i manteniment duplicat. Les IAs no saben quin fitxer utilitzar.
Solució: Unificar en una sola ubicació: `src/components/universal/UniversalCard.jsx`. Eliminar el duplicat de `src/components/ui/`.

### 🟡 PUNTS ALTS (PRIORITAT ALTA)

**3. 📚 Falta de Documentació de Tokens de Disseny**
Problema: Els fitxers `design-tokens.json` i `design-tokens.css` no tenen documentació associada.
Solució: Crear un fitxer `STYLEGUIDE.md` en `_wiki_de_poble/02_saber/`.

**4. 📜 CSS Massiu - index.css**
Problema: El fitxer `src/css/index.css` té 4,554 línies de codi, massa gran per a un únic fitxer CSS.
Solució: Dividir en mòduls CSS seguint la metodologia SMACSS o BEM.

**5. 🎨 Paleta de Colors No Documentada**
Problema: No hi ha una paleta de colors centralitzada i documentada accessible per a les IAs.
Solució Implementada en la Demo: Establir colors primaris, semàntics, de text, de background i de border a `:root`.

**6. 📐 Jerarquia de Títols No Explicita**
Problema: No està clarament documentat com s'estilitzen els diferents nivells de títols (H1, H2, H3, etc.).
Solució: Crear un fitxer `typography.md` documentant mides de font, colors, pesos i line heights.

### 🟢 PUNTS MITJANS (PRIORITAT MITJANA)

**7. 🔧 Fitxers Absents (No Crítics)**
Problema: El manifest indica que falten `public/gestoria/index.html`, `public/gestoria/tauler.js`, i `public/assets/pedra-seca.css`.
Solució: Netejar referències o crear els fitxers.

**8. 🏗️ Falta de Variables CSS Globals**
Problema: El manifest no mostra variables CSS globals de manera explícita.
Solució Implementada: Definir `--spacing-md`, `--radius-md`, `--shadow-sm`, etc., al `:root`.

## 2. INSIGHT CLAU

Les IAs necessiten regles explícites i inèdites. El que és òbvi per a un humà (que tot ha de ser Sans-Serif) no ho és per a una IA. La documentació i el codi han de ser auto-explicatius i blindats contra interpretacions errònies.
