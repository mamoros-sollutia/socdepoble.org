§2Diagnòstic del canal

La prova d'al·lucinació ja ha donat un resultat, encara que no és el que esperàvem: el primer punt cec no és del CSS ni del JSX — és del canal de transmissió. Una instrucció que exigeix fidelitat estricta («analitza estrictament el codi adjunt») sense que el codi estiga adjunt és el caldo de cultiu perfecte de la invenció: la pressió de complaença empeny el model a omplir el buit amb els seus priors estadístics — paletes terroses, serifs rústiques, blaus corporatius — i a lliurar-los com si foren especificació.

La decisió metodològica d'esta acta és doble: no fabricar cap valor del sistema, i convertir la manca de font en el propi material de l'auditoria. Per açò el document que tens davant està compost en serif, deliberadament: perquè no és Pedra Seca i no vol semblar-ho. Quan el bundle arribe, esta pàgina perderà el sentit i se substituirà per la reproducció verificable.

L'activació canvia la paleta i la tipografia d'este document per uns valors inventats amb aparença d'oficialitat. És la demostració práctica del risc, no una proposta de disseny.

Q-01

Tipografia de base

Evidència«Sans-Serif per defecte» — sense família, sense mida arrel, sense stack de substitució.

Tanca amb C-02 · C-03

El mur de pedra en sec no porta ciment: cada carreu aguanta els altres per pes i per ofici. Igual que el text: només se sosté si cada element té el lloc exacte que el sistema li assigna. La font ho ha de dir tot; el silenci dels marges també.

La família i l'interlineat són decisions independents, i cap de les dues consta. Un «stack de substitució» no documentat vol dir que cada navegador — i cada model — resolverà la seua.

§4Clàusules de blindatge

Set esmenes tècniques, ordenades per retorn. Les tres primeres haurien evitat l'incident dels H3 en serif; la primera hauria evitat esta acta sencera.

C-01

Manifest amb hash al capdamunt de cada bundle

Un bundle que no pot demostrar el seu contingut no és evidència. Exigeix que tota petorreta verifique la presència dels fitxers que cita abans de donar la missió per llançada — i que el model declari la mancança en lloc d'omplir-la.

<!-- MANIFEST DEL BUNDLE (primer bloc, sempre)
files: 2
  1. DesignSectionContent.jsx   sha256:978f…c283  requerit
  2. index.css                  sha256:…          requerit
Regla: si files = 0 o un hash no casa, la missió
es NO EXECUTABLE. Declara-ho; no inventes. -->
C-02

Dues capes de tokens: literal i semàntica

Els noms poètics («pedra», «argila») sense valor literal conviden a inventar. El valor numèric ha d'existir una sola vegada, al nivell literal; els àlies només el referencien.

/* capa 1 — literals: únic punt de veritat */
:root{ --sd-12:0.75rem; --sd-16:1rem; --sd-24:1.5rem; }
/* capa 2 — àlies semàntics (mai valors nous) */
:root{ --sd-gap:var(--sd-12); --sd-block:var(--sd-24); }
C-03

Reset explícit de capçaleres i elements nus

Quan el CSS no diu res sobre un element, el model barreja el default del navegador amb el seu propi prior. Cada element que existisca a la UI ha de tindre una línia que el declare — encara que siga per a dir-ho tot.

h1,h2,h3,h4,h5,h6{ font-family:var(--sd-font-sans); color:var(--sd-ink); }
h3{ font-size:1.25rem; font-weight:600; line-height:1.3;
    margin:var(--sd-block) 0 var(--sd-12); }
/* AVÍS: cap encapçalament d'este sistema usa serif. */
C-04

Golden HTML: la font de veritat és executable

Adjunta sempre una pàgina de referència renderitzada des del codi real (la mateixa DesignSectionContent com a HTML executat). Un model davant d'evidència executable al·lucina molt menys que davant d'una descripció. És la defensa directa contra el conegut «H3 en serif».

C-05

Contractes de component inline

Props, variants i prohibicions al propi JSX. Un «NO admet…» que viatja amb el codi val més que qualsevol pàgina de documentació apartada, perquè no es pot perdre pel camí.

/**
 * UniversalCard — jerarquia: títol(600) > cos > accions.
 * variants: "plana" | "vora" | "elevada"   (per defecte: "vora")
 * NO admet: ombra difusa, fons amb degradat, títol en serif.
 */
C-06

Clàusula anti-priming al preàmbul

«Pedra Seca» és un identificador de projecte, no una directiva estètica: el nom no implica paleta terrosa, serif rústica ni textura de pedra. Sense esta frase, el nom mateix és una instrucció fantasma que cada model llig a la seua manera.

C-07

Referències wiki resoltes o marcades

Al bundle aparellat, cada [[enllaç]] (logos, genotip, governança…) ha d'arribar resolt o declarat explícitament irrellevant per a la missió. Una referència penjada és un esvoranc per on entra la invenció.
