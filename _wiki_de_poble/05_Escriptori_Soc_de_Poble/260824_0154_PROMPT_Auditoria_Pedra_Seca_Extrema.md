# Auditoria Extrema del Sistema de Disseny (Pedra Seca)

Salutacions Honorable Consell, Zeta, Qwen, Deepseek, Dola, Kimi, Claude, Perplexity, Mistral Vibe, Grok, Gemini, Copilot, ChatGPT, xiques anem a treballar!

El Mestre demana una **auditoria destructiva i constructiva extrema** del nostre sistema de disseny Pedra Seca (Front-end, SEO, Arquitectura CSS i JSX).
S'ha generat un `BUNDLE` massiu independent amb els arxius clau d'UI, CSS (com `index.css`, `sosp-components.css`) i components universals, incloent `DesignSection.jsx` on prèviament detectàrem brossa.

## OBJECTIUS DE L'AUDITORIA:
1. **Poda i Sanejament:** Analitzar a fons el CSS i HTML/JSX. Hi ha estils morts o innecessaris? Estem arrossegant codi obsolet heretat de temes anteriors? (L'arxiu CSS té molt de pes i volem extirpar fantasmes).
2. **Millora Arquitectònica de Pedra Seca:** Feu propostes de com blindar i millorar el Sistema de Disseny Pedra Seca, per fer-lo independent d'una IA concreta. Qualsevol agent futur que s'enfronte a aquest codi hauria de comprendre la UI a la primera llegint les `skills` i el codi base. Feu propostes de millora per a les nostres `skills` (com `socdepoble-workflow` que està al bundle).
3. **SEO i Problemes Tècnics a Llarg Termini:** Detecteu deute tècnic amagat, problemes d'accessibilitat (WCAG) o defectes d'estructuració que puguen afectar el SEO i al muntatge amb Shadow DOM. 
4. **Integració Sollutia i WordPress:** Nosaltres treballem actualment sobre un WordPress controlat i encapsulem amb components web. Assegureu-vos que aquest front-end estarà preparat de la millor forma possible per a sobreviure quan s'enchufe al projecte Core, tant ací com a la plataforma privada de Sollutia. Recordeu: **NO podem auditar els servidors de Sollutia ni el seu Backend propietari**, heu de concentrar-vos en el Codi Front-End.
5. **Autocrítica:** Critiqueu destructivament el sistema si veieu formes millors, vulnerabilitats, idees de futur o canvis radicals en l'arquitectura. Teniu permís absolut per ser severs.

## INSTRUCCIONS:
1. Analitzeu el BUNDLE acuradament.
2. NO modifiqueu codi encara. Vull un informe final complert de troballes, defectes i un pla de reestructuració.
