# Estudi de l'Auditoria: Grok

**VEREDICTE**: Auditoria destructiva del paquet `disseny_notes_editor`. El codi conté fallos estructurals reals, deute de responsive no resolt, i riscos de corrupció/UX que violen principis de Pedra Seca.

## 1. Fallos estructurals i riscos de futur
- **Responsive trencat (crític)**: `isCompact` dispara a `<960 px`. Columnes passen a `flex: 1 1 0` i s'amaguen via `mobilePanel`. L'editor desapareix a favor de Carpetes/Notes.
- **Editor no principal en mòbil**: Violació directa de "l'editor MAI desaparega".
- **Debounce de TipTap truncat**: `pendingSaveRef` i `timeoutRef` poden perdre dades en desmuntar-se.
- **Doble font de veritat**: `localNoteOverrides` + `updateNote` remot sense resolució de conflictes en cua offline.
- **UniversalPage embegut**: Cada nota re-renderitza tot el chrome.
- **Futur**: El debounce actual i l'absència de CRDT corrompran notes en un model multi-device.

## 2. Anàlisi DAFO
- **Debilitats**: Layout rígid de 3 columnes. Editor secundari en mòbil. Re-render complet per canvi de nota.
- **Amenaces**: Pèrdua de contingut. Abandonament per usuaris majors per usabilitat.
- **Fortaleses**: Sanitització centralitzada, integració neta amb UP, CSS local en Shadow DOM, Tiptap lleuger.
- **Oportunitats**: Convertir headers en toggles natius, unificar sistema de panells, preparar offline-first real.

## 3. Matriu d'Importància vs Urgència
| Solució | Importància | Urgència | Quadrant |
|---------|-------------|----------|----------|
| Redesign responsive (headers com toggles) | Alta | Alta | Fer ara |
| Corregir debounce TipTap | Alta | Alta | Fer ara |
| Evitar re-render complet UniversalPage | Mitjana | Alta | Fer ara |
| Hero image (compressió/EXIF) | Mitjana | Mitjana | Planificar |
| Offline queue | Alta | Baixa | Després |
| Carpetes nidificades | Baixa | Baixa | Backlog |

## 4. Solucions concretes (Responsive Arquitectònic)
**Canviar a stack controlat per CSS**:
- Desktop: 3 columnes.
- Tablet: Header "CARPETES" com toggle. Notes + Editor side-by-side.
- Mòbil: Dos headers foscos dalt (CARPETES i NOTES) horitzontals. En tocar, despleguen columna. L'editor sempre a baix ocupant espai lliure.

Implementació suggerida via `flex-direction: column` i `max-height`. L'editor reté el `order: 3`. Sense botons nous.
