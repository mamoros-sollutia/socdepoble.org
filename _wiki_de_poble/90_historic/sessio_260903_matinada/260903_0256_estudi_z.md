## 3. Auditoria d'icones de la barra de format

### 3.1 Troballa: per què pareixen "d'una altra col·lecció"

No hi ha barreja de biblioteques — tot és `lucide-react`, com ja advertia l'aclariment tècnic de la petorreta. El que passa és que **Lucide conté dues famílies visuals**:

| Família | Exemples | Aspecte |
|---|---|---|
| Línia geomètrica | `Search`, `Languages`, `List`, `Link2`, `Undo2`… | traç pur — la de tota l'app |
| Lletra tipogràfica | `Bold`, `Italic`, `Underline`, `Strikethrough`, `Superscript`, `Subscript`, `Heading1`–`Heading6` | **lletres amb serifa** dibuixades com a traç |

La barra de format barreja la família tipogràfica amb la geomètrica → sensació de "col·leccions diferents" i "estil antic". **És un límit del catàleg, no un error d'integració.**

### 3.2 El límit honest

Dins de Lucide, les icones d'edició geomètriques són les de funció estructural: `Type`, `Pilcrow`, `Hash`, `List`, `ListOrdered`, `Quote`, `Link2`, `Undo2`/`Redo2`, `RemoveFormatting`, `AlignLeft/Center/Right/Justify`, `Highlighter`, `Eraser`, `WrapText`. **Cap d'elles codifica "negreta", "cursiva" o "ratllat" sense ambigüitat.** El catàleg no té lletres sans per a estes funcions.

→ La restricció "100% Lucide + 100% línia geomètrica + mateixes funcions" **no és satisfactible tal com està formulada**. Queda constància i es proposen tres vies.

### 3.3 Proposta

**Opció A — Botons tipogràfics (RECOMANADA).** Els quatre controls deixen de ser icones i passen a ser **glifs de text** dins el mateix xassís de botó: `B` (pes 700), `I` (itàlica), `S` (amb `line-through`), `H₂` (subíndex), en **Noto Sans — ja embarcat** (`src/assets/fonts/noto-sans.css`). El glif *demostra* la funció, és sans per construcció i encaixa amb el traç geomètric del voltant. És el patró dels editors madurs. La regla "totes les icones de Lucide" es respecta per a totes les *icones*; estos són **controls tipogràfics, no icones** (com el "B" de tot processador de text). La IAIA continua sent l'única icona pròpia.

```css
.sdp-notes__glif {
  font: 700 15px/1 "Noto Sans", sans-serif;   /* mateixa caixa que els botons d'icona */
  width: 36px; height: 36px;
  display: grid; place-items: center;
}
```

*Nota tècnica:* verificar els `@font-face` de `noto-sans.css`; si només hi ha el pes 400 embarcat, el navegador sintetitza negreta i itàlica (acceptable a pantalles petites; si no, afegir el pes 700 a la font ja present).

**Opció B — SVG propis "estil Lucide".** Dibuixar B/I/S/H₂ sans amb la geometria exacta de Lucide (viewBox 24×24, `stroke-width: 2`, extrems arrodonits) i allotjar-los a `src/icons.jsx` — el mateix fitxer que ja allotja l'excepció de la IAIA. Visualment indistingibles de la família. **Requereix ratificació del Mestre** com a segona excepció documentada (la petorreta només eximeix la IAIA).

**Opció C — Lucide estricte.** Mantindre `Bold/Italic/Strikethrough/Heading2` i aïllar-les com a clúster tipogràfic dins la barra. Compliment literal de la regla; **no resol la queixa** ("lletres antigues"). Queda com a constància si el Consell prioritz la lletra de la regla sobre l'esperit.

**Barra objectiu (Opció A):**

| Funció | Control | Origen |
|---|---|---|
| Negreta | glif `B` (700) | text Noto Sans |
| Cursiva | glif `I` itàlica | text |
| Ratllat | glif `S` + `line-through` | text |
| Encapçalat H2 | glif `H₂` | text |
| Llista / ordenada | `List` / `ListOrdered` | lucide-react |
| Enllaç | `Link2` | lucide-react |
| Desfer / refer | `Undo2` / `Redo2` | lucide-react |
| Traure format | `RemoveFormatting` | lucide-react |

**Especificació d'unificació (obligatòria a tota l'app, estiga on estiga la icona):**

- Icona 18 px dins botó 36 px (o el token corresponent); `stroke-width: 2` (1.75 en barres denses); viewBox intacte.
- Caixa fixa per icona (`display: block; flex-shrink: 0`) — evita les mides òptiques desiguals que amplifiquen la percepció de "col·leccions diferents".
- `role="toolbar"` al contenidor; `aria-pressed` als toggles; `aria-label`/`title` en valencià; focus visible amb tokens Pedra Seca; contrast AA (vegeu `a11y_seo_trellat`).

### 3.4 Excepció IAIA (intocable)

**Capa 4 — Autocorrecció del GENERADOR de prompts (el que demana la petorreta).** Esmena al `PROTOCOL_PETORRETA` i a les plantilles de generació:

1. Qualsevol prompt que toque `_wiki_de_poble/**` **ha d'incloure** un bloc `VERIFICACIÓ PRÈVIA:` amb el sha256 del fitxer que vol reescriure, obtingut de **llegir-lo abans** d'emetre.

3. L'agent receptor executa `node scripts/vigia_plantilles.mjs check` com a primer pas i refusa escriure plantilles si el prompt no duu hash coincident.

const REFLEX = ".sdp-reflex/plantilles";   // dipòsit segellat (còpia bona)
const PAPER  = ".sdp-paperera";

const sha = (f) => createHash("sha256").update(readFileSync(f)).digest("hex");

const invariantsOk = (ruta, reg) => {
  const txt = readFileSync(ruta, "utf8");
  if (txt.split("\n").length < reg.linies * (1 - reg.tolerancia)) return false; // pèrdua massiva de format

function restaurar(ruta, motiu) {
