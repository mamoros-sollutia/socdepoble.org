# Auditoria tècnica v1.4.0 — IAIA MarIA (Estudi Grok)
(Consell · Pedra Seca · Trellat · Higiene Cognitiva)

### 1. Arquitectura inversa (desmuntatge)

**Nucli runtime**
- SPA Preact (compat React) + Vite.
- Alias forçats: `react` → `preact/compat`. Correcte per Baseline 2022.
- Standalone WordPress: `vite.standalone.config.js` → ESM (`type="module"`) + code-splitting. Entrada `src/wp-standalone.js`.
- Host: `src/host.js` + Web Component `<soc-de-poble>`. Shadow root + tokens CSS propis. Anti-FOUC via `sdp_bootstrap_theme` + `--sdp-bg`.
- Dades: dual (seed local + Supabase). `supabaseBackend.js` + `oauthRelay.js` + `public/auth/callback.html`.
- Rutes: React Router + manifest SEO generat (`seo-routes.json`). Plugin WP cedeix prefix complet amb HTTP 200.

**Cervell / governança**
- Wiki canònica `_wiki_de_poble` (4 pilars + 90_historic).
- Skills a `.agents/skills/` (mirall a wiki).
- Portes mecàniques (tractors): frontmatter, esquemes, frontera-auth, consell, cromàtic, doctrina, persistència, etc.
- Canonada d’escriptura obligatòria (`canonada.mjs`). Qualsevol generador que escriga `fs` directe → bloqueig.
- SDP-LOCK + Reflex + baseline de deute (`.*-deute.json`). Fail-closed.

**Versió 1.4.0 específica**
- Preact + PWA (VitePWA, autoUpdate).
- Standalone ESM + lazy chunks.
- Optimitzacions explícites per iPad A10 (Baseline 2022).

### 2. Valoració crítica

**Fortaleses (Pedra Seca real)**
- Zero Tailwind al core. Tokens propis + CSS pur.
- Governança mecanitzada: 9+ portes de consciència contextual + deute segellat. No és cosmètica.
- Frontera d’auth auditada (A1–A6). Relé OAuth + llista blanca d’orígens per igualtat estricta.
- Dualitat online-first (ADR-2026-08) declarada sense mentir sobre la meta local-first.
- Skills amb frontmatter + triggers + mirall. RAG i teixidora existen (encara que amb limitacions detectades).
- Plugin WP soberà: no depèn de `wp-element`, config pública filtrada, credencials Supabase només de constants de servidor.

**Deute i riscos detectats (bloquejants o gairebé)**
1. **Skills inabastables (P5)**  
   RAG arrelat a `_wiki_de_poble`. `.agents/skills` queda fora si el caminador descarta directoris amb punt i no fa excepció. Topologia d’estrela permanent si el mirall està a JURISDICCIONS_EXCLOSES.

2. **Doble font canònica del Consell (P7)**  
   Llistes dures de models dins de skills + punters a `02_EQUIP_IA.md`. Dues regles = zero regles.

3. **Esquema frontmatter**  
   Dos validadors històrics (`schema.json` vs `esquema_frontmatter.json`). La porta `tractor-esquemes` ja els obliga a coincidir, però qualsevol divergència futura trenca Reflex + porta.

4. **Acompanyants morts (P9)**  
   Fitxers `.json/.mjs` dins de skills que cap script del projecte llegeix → codi mort disfressat de cànon.

5. **Auth edge**  
   Si `RELAY_PER_DEFECTE` i els orígens documentats a `callback.html` divergeixen, el Camí 1 (postMessage) falla en silenci i cau al fallback de storage/timeout 180 s.

6. **Baseline 2022**  
   Preact + ESM + PWA és correcte, però el pes de `src/css/index.css` (~119 kB) + `UniversalComponents.jsx` (~45 kB) + i18n (~83 kB) encara pressiona l’A10 en cold start. Code-splitting al standalone ajuda, però el core SPA principal no està igual de fragmentat.

7. **Sollutia-first**  
   Declarat. Cap origen de client a la llista blanca d’auth → component incrustat en WP de tercers no pot fer login Google sense actualitzar la llista (avís A4).

### 3. Propostes de millora contínua (ordre de prioritat Trellat)

**P0 – Consciència i topologia (aquesta setmana)**
- Obrir excepció explícita a RAG / teixidora per `.agents/skills`. Una sola línia de whitelist.
- Unificar font del Consell: només `02_EQUIP_IA.md`. Eliminar llistes dures de skills.
- Executar `tractor-esquemes` + `tractor-frontmatter --baseline` i tancar divergències restants.
- Netejar acompanyants sense consumidor (P9) o documentar-los com a contracte explícit.

**P1 – Rendiment Baseline 2022**
- Particionar `UniversalComponents.jsx` i `i18n.js` per ruta/secció (dynamic import).
- Revisar `index.css`: eliminar regles mortes, consolidar tokens, diferir non-critical.
- Mesurar cold start real en iPad A10 (Lighthouse + WebPageTest) amb el standalone ESM actual. Objectiu: TTI < 3,5 s en 3G.

**P2 – Auth i frontera**
- Una sola constant d’origen de relé. Generar `ORIGENS_PERMESOS` des de la mateixa font en build si cal.
- Validar `sdp_path` amb la mateixa rigorositat que `sdp_origin` (A5).
- Afegir test mecànic (porta) que falli si el relé JS ≠ HTML.

**P3 – Sobirania local (llarg termini, sense mentir)**
- Continuar Online-First. Quan arribi el moment, el motor offline ja té skill pròpia (`MOTOR_OFFLINE`). No avançar-lo abans que el deute P0–P2 estigui tancat.
- Seed Supabase + seed local han de ser generats per la mateixa canonada.

**P4 – Higiene**
- Qualsevol nou generador de documents ha de passar per `canonada.mjs`. La porta P4 ja ho exigeix.
- Mantenir zero dependències runtime noves. Si cal una utilitat, avaluar si es pot fer amb 20 línies pròpies.

### 4. Veredicte

El sistema és coherent amb la doctrina que declara.  
Preact + ESM + portes mecàniques + SDP-LOCK és arquitectura de pedra seca real, no eslògan.  

Els riscos principals no són de codi “brut”, sinó de topologia cognitiva (skills inabastables, doble font del Consell, relé d’auth divergent). Aquests es tanquen amb canvis petits i portes ja existents.

No hi ha risc de destrucció que activi SDP-LOCK ara mateix.  
El deute està mesurat i les portes el limiten.

**Següent pas recomanat**  
Executar en ordre:
1. `node tooling/gates/tractor-esquemes.mjs`
2. `node tooling/gates/tractor-frontera-auth.mjs`
3. Revisió manual de P5 (RAG) + unificació Consell
4. Mesura real A10 del cold start actual

Quan aquestes quatre portes passin en verd, la v1.4.0 queda consolidada i es pot planificar el següent increment de sobirania sense autoengany.
