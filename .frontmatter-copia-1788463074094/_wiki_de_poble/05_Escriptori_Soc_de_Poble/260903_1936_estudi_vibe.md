## 💡 **BLOC DE SOLUCIONS CREATIVES (Imaginació Analítica Humana)**

### **🔮 1. SISTEMA DE "PEDRA SECA" PER A COMPONENTS**
**Concept:** Aplicar la filosofia de **Pedra Seca** (construcció sense morter) als components React.
**Implementació:**
- Cada component ha de ser **autocontingut** (com una pedra)
- **Encapsulament total** de lògica, estils i estat
- **Reutilització màxima** (com les pedres en una paret)
- **Sense dependències externes** (com el morter que no s'utilitza)

**Exemple:**
```jsx
// Component "Pedra" (autocontingut)
const PedraButton = ({ children, onClick }) => {
  const [isPressed, setIsPressed] = useState(false);
  return (
    <button
      className="pedra-button"
      onClick={onClick}
      onMouseDown={() => setIsPressed(true)}
      onMouseUp={() => setIsPressed(false)}
    >
      {children}
    </button>
  );
};
```

---
### **🔄 2. SISTEMA DE "TRELLAT" PER A ESTAT GLOBAL**
**Concept:** Usar un **trellat** (estructura de fusta entrecreuada) per a gestionar l'estat global de forma lleugera.
**Implementació:**
```javascript
// src/trellat/estat.js
const trellat = {
  // Cada "barra" del trellat és un mòdul independent
  usuari: {
    nom: 'Javi',
    rol: 'admin'
  },
  temes: {
    mode: 'fosc',
    colors: { primary: '#000' }
  },
  // ...
};

// Accés directe (sense React Context)
import { trellat } from './trellat/estat';
console.log(trellat.usuari.nom); // "Javi"
```
**Avantatges:**
- ⚡ **Més ràpid** que React Context
- 🧩 **Mòduls independents** (fàcil de mantenir)
- 📦 **Mida reduïda** (sense wrappers de Context)

---
### **🌿 3. SISTEMA DE "SOLLUTIA-FIRST" PER A RENDIMENT**
**Concept:** Prioritzar solucions **lleugeres i simples** (Sollutia = solució sense complicacions).
**Principis:**
1. **Evitar libreries externes** si es pot fer amb VanillaJS
2. **Usar CSS natiu** en lloc de libreries d'estils
3. **Minimitzar l'estat global**
4. **Carregar només el necessari** (lazy loading agressiu)

**Exemple:**
```javascript
// ❌ Amb libreria externa (Moment.js - 70KB)
import moment from 'moment';
moment().format('DD/MM/YYYY');

// ✅ Amb VanillaJS (0KB addicional)
new Date().toLocaleDateString('ca-ES', {
  day: '2-digit',
  month: '2-digit',
  year: 'numeric'
});
```

### **🔥 4. ALGORISME ATRC (Termodinàmica Reflexiva i Cooldown)**
**Concept:** Aplicar l'algorisme **ATRC** per a mantenir la **salut termodinàmica** del sistema.
**Implementació:**
```javascript
// src/atrc/monitor.js
class ATRC {
  constructor() {
    this.temperature = 0; // 0-100
    this.cooldown = false;
  }

  // Monitoritza la "temperatura" del sistema
  checkTemperature() {
    const cpuUsage = this.getCPUUsage();
    const memoryUsage = this.getMemoryUsage();

    this.temperature = (cpuUsage + memoryUsage) / 2;

    if (this.temperature > 80) {
      this.triggerCooldown();
    }
  }

  // Refredament automàtic
  triggerCooldown() {
    this.cooldown = true;
    this.optimizeResources(); // Reduir càrrega
    setTimeout(() => { this.cooldown = false; }, 5000);
  }
}
```
**Accions de cooldown:**
- Descarregar mòduls no utilitzats
- Reduir freqüència de renders
- Comprimir assets en temps real
